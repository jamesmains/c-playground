# What is this?
This is a compilation of projects as I learn more about C as well as somewhere for me to write out my notes and thoughts as I learn the language. There may be nothing entirely impressive in this repo, but it's fun working with a new language.

# Projects
In order it was added
## Basics
This is not a single project meant to be built together but rather just random things I wanted to try out. Coming from a C# background I'm working a bit backwards learning how to manage memory and crazy things like "pointers".
## RPG
I'm obsessed with working on RPGs. This was a test to have a character that could deal damage and use items. It's a really basic loop of fighting a random monster (Troll so far undefeated by myself) and going to a shop to supply yourself.
## Snake
While not quite ready to tackle graphics I did want to have some sort of visual representation of a game, so naturally Snake made the most sense to recreate. Very basic and a little flawed, but the loop of getting fruit and trying to avoid your growing body are there.
## Hangman
This project is unique in that I used almost no online resources when making it. I wanted to see how far I could get just writing it myself without needing to look anything up. I tripped right at the end for detecting the win condition.
## Todo
First project sinces Basics that isn't a game. This was to get the hang of file reading and modifying.
## RPG2
After getting a better hang on how C works, I wanted to remake the RPG project to see how big I could make it! While
it's still in a terminal I've added a new mode called Explore as well as revamped (or completely reworked) all the
systems. Delve into Termina to fight, level, and explore! Gear up and face the mighty Troll! The troll is actually pretty weak tbh. I died more to the spiders.
### RPG2 Postmortem
#### Planning
What I'd like to do better going forward is more planning. Most of these projects are just Jesus take the wheel
situations, but with that I quickly ran into overlapping responsibilities between files.
#### Scope
For this project I kept it really lean. I listed out everything I wanted and trimmed it well down based on what I was
comfortable on working while still learning more about C. This worked out really well and kept the project moving!
There was a few things that got cut but still linger in the code (item requirements, various unused Stats, and enemy ai is lack luster).
#### Graphics
While terminal is a pretty poor interface for the modern gamer, there was something charming about the simple "graphics". That being said, there was plenty I couldn't convey with just text. The title screen was one tiny toe in
the pool of better graphics but this won't be much use until I start looking at graphics libraries. Hopefully RPG3!
