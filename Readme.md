# What is this?
This is a compilation of projects as I learn more about C as well as somewhere for me to write out my notes and thoughts as I learn the language. There may be nothing entirely impressive in this repo, but it's fun working with a new language.

# Projects
In order it was added
## Basics
This is not a single project meant to be built together but rather just random things I wanted to try out. Coming from a C# background I'm working a bit backwards learning how to manage memory and crazy things like "pointers".
## RPG
I'm obsessed with working on RPGs. This was a test to have a character that could deal damage and use items. It's a really basic loop of fighting a random monster (Troll so far undefeated by myself) and going to a shop to supply yourself.
## Snake
While not quite ready to tackle graphics I did want to have some sort of visual representation of a game, so naturally Snake made the most sense to recreate. Very basic and a little flawed, but the loop of getting fruit and trying to avoid your growing body are there.
## Hangman
This project is unique in that I used almost no online resources when making it. I wanted to see how far I could get just writing it myself without needing to look anything up. I tripped right at the end for detecting the win condition.
